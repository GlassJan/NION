이 프로젝트는 Apache 2.0 라이선스를 따릅니다. 네트워크 서비스(SaaS/API)를 포함하여 소스코드 공개 의무 없이 상업적으로 이용하거나, 또는 인수(?)를 원하시는 분들은, wtiger0718@naver.com으로 문의해 주시기 바랍니다.

Github를 처음 다뤄보는 관계로, 이 파일들은 AI에 의해 작성되었습니다. 양해 부탁드립니다.

## 실행

Node.js 24 이상을 설치한 환경에서 폴더 안의 터미널을 엽니다. 외부 패키지 설치는 필요 없습니다.

```sh
npm run demo:neuron
npm run demo:synapse
npm run demo:formation
npm test
npm run check:color
npm run check:contribution
npm run verify
```

- 뉴런 데모: 한 뉴런에 정해진 전류 자극을 주고 전압과 발화 관측을 출력합니다.
- 시냅스 데모: 시간쌍으로 강화·약화하고 저장·복원 결과를 출력합니다.
- 형성 데모: **합성 테스트 바이트**로 기존 QHON의 3×3×3 경로 생성기를 실행합니다. 실제 QRNG 연구 결과로 집계하지 않습니다.
- 테스트: 기존 시냅스 검사, 한 세포 복원, 실제 세포 발화와 학습의 연결, 형성 경로·압축·입력 계약을 확인합니다.
- 원본 색·기여 검사: 기존 코드의 기하·기록 보존 조건을 확인합니다. 의미·감정이 생성됐다는 검사가 아닙니다.

실제 ANU 응답에서 추출한 little-endian uint32 바이트를 가진 경우 다음처럼 재생할 수 있습니다.

```sh
node examples/formation.mjs --qrng-file private-data/recorded-words.bin
```

원응답, 수신 출처, 변환 규칙, 해시를 별도로 보관해야 합니다. `anu-qrng-recording`은 호출자의 선언이며 프로그램이 양자 기원을 인증하는 것은 아닙니다. API의 JSON 원문을 그대로 바이너리 파일로 넣으면 안 됩니다. 자동 API 수집기나 인증 정보는 이 묶음에 없습니다.

## 형성 규칙의 두 층

### 니온 GNN의 사용자 설계

100×100×100 배치와 완전 연결 구상, 세 좌표평면의 동작·사고·인식 역할, R/O/Y/G/B/M/P/W 혼합, 선분 길이의 의미 가중, 뉴런별 감정 합, 전체 사고굴절선 보존, 선택적 소거 세포가 포함됩니다.

하지만 평면별 역할 대응, 색 혼합의 물리적 정의, 감정 종류·배치, 다음 경로 선택, 분기·종료, 온라인 학습 통합은 모두 확정·구현되지 않았습니다. `GNN_DESIGN_RULES`는 이를 코드에서 읽을 수 있게 정리한 **이번 배포용 선언**입니다. 기존에 완성된 GNN 형성기라고 주장하지 않습니다.

### 지금 실행할 수 있는 QHON 참고 구현

`formQhonReference()`는 기존 27개 위치의 조화장 기반 경계 성장 함수를 호출합니다. 현재 집합의 이웃 후보를 고르고, 조화장 값의 eta승을 확률 가중으로 사용하며, 지정 sink가 포함되거나 최대 26간선에 도달하면 끝납니다. 기존 경계의 최소 번호 부모 선택은 이 구현의 결정 규칙입니다.

완전 연결을 만드는 알고리즘이 아니며 노드 좌표와 간선을 반환할 뿐, 뉴런 발화·학습 상태·감정·생각을 자동 생성하지 않습니다. 별도의 선형 주소 비트마스크가 27개 위치에 맞춰져 있어 상수 N만 바꿔 확대하면 안 됩니다.

## 뉴런과 시냅스의 범위

뉴런은 Neuron Set에서 사용한 ControlNeuron 1.0.0입니다. 인간 대뇌피질의 특정 세포형에 보정된 모형이 아니라, 고전 HH형 계산에 흥분·억제 전도도와 합성 적응 상태를 더한 계산 참조입니다. ATP·분자 확산·세포 성장·QHON 전체 화학 상태는 이 단일 세포 클래스에 없습니다.

PlasticSynapse는 전도도 크기를 학습하는 STDP 상태입니다. 별도의 전달 지연과 흥분·억제 종류는 `TinyNetwork`가 다룹니다. 화학 방출 억제 모형이나 모든 보상 학습 정책이 이 파일 안에 들어 있는 것은 아닙니다.

기본 STDP는 0.4nS에서 시작하고, 0.25~14nS 범위, 강화·약화 계수 각 0.001nS, 시간상수20ms를 씁니다. 공학 설정이며 인간 시냅스의 보편 상수가 아닙니다. `learn()`은 명시적 시간쌍을 받아 한 번 갱신하며 최대 이력10,000개 제한이 있습니다.

## 최신 QHON과 연결할 때

이 묶음은 최신 QHON 전체 엔진을 옮긴 것이 아닙니다. 후속 QHON은 27개 세포의 별도 결합 엔진에서 자원·억제·학습 상태를 시험합니다. 따라서 여기의 ControlNeuron/PlasticSynapse를 조합했다고 후속 M·N 연구가 그대로 재현되지는 않습니다.

제5가설의 최신 부가가설은 **3차원 원형 → 층 표식 통합 평면 → 선 표현 → 연결된 연속 사고**입니다. 구체적인 선 부호화와 연속 사고 기능은 여기에서 구현하지 않았습니다. 정확한 원본 복원과 해석 변이를 분리하며, 의미가 뒤집히는 기억 오류는 허용하지 않는다는 제약을 유지합니다. 자세한 연결 방향은 [아키텍처](docs/ARCHITECTURE.md)를 보세요.
