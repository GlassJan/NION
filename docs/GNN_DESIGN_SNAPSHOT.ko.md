## 1. 이름과 핵심 정의

- 현재 사용자가 부르는 명칭: **니온 GNN**.
- 핵심 표현 단위: **시냅스굴절선**.
- 시냅스굴절선은 신호가 뉴런들을 순서대로 거치며 형성하는, 여러 선분으로 이루어진 경로입니다.
- 각 선분은 자체 의미를 가지며, 세 좌표평면의 색 논리로 그 의미를 구성합니다.
- 각 선분의 길이는 그 선분의 의미가 전체 경로에서 갖는 가중입니다.
- **굴절선 전체가 인식·사고·동작을 포함하는 하나의 ‘생각’입니다.** 최종 뉴런 하나, 최종 혼합색 하나 또는 모든 의미의 단순 평균으로 생각을 대체한다는 설계가 아닙니다.
- 각 뉴런에는 기본 감정을 배정합니다. 경로가 통과한 뉴런들의 감정 합이 해당 생각의 최종 감정입니다.
- 시냅스에는 기하학적 길이와 별도로 학습 가중치가 있습니다. 최신 결정은 활성화마다 무조건 증가시키는 규칙에서 생물학적 가소성을 단순화한 강화·약화·포화 규칙으로 발전했습니다.
- **소거 세포**는 반복 실패한 시냅스굴절선을 평가하고, 임시 억제와 원인 검증을 거쳐 유해한 연결을 선택적으로 소거하는 관리 기능입니다. 공유 연결과 성공 경험을 보호하며, 상세 절차는 13절을 따릅니다.

## 2. 공간 배치와 연결

사용자의 원래 구상은 **100 × 100 × 100 = 1,000,000개 뉴런**을 큐브에 배치하고 모든 뉴런 사이를 시냅스로 연결하는 것입니다. 최초 발화 뉴런에서 다음 뉴런으로, 다시 다음 뉴런으로 신호가 이어지며 최종 경로가 형성됩니다.

완전 연결을 먼저 만들면 경로의 활성화와 연결 자체의 생성은 구분해야 합니다. 연결 생성 시점과 기존 연결의 선택·강화 방식은 아직 정하지 않았습니다. 반복 실패에 따른 소거는 13절의 조건부 관리 절차를 따르며, 경로가 활성화될 때마다 연결을 자동 생성·제거한다는 규칙은 아닙니다.

자기 연결을 제외하고 A→B와 B→A를 별도 시냅스로 가정하면 시냅스는 **999,999,000,000개**입니다. 연결마다 독립적인 4바이트 가중치만 저장해도 약 **4TB**입니다. 이는 구조·지연·학습 상태·뉴런 상태·로그를 제외한 십진 단위 계산입니다. 원래 구상에서 방향성과 자기 연결 처리까지 확정한 것은 아닙니다.

검토 중 제안된 대안은 주변 연결과 일부 장거리 연결을 사용하는 희소 구조, 필요할 때 연결을 만드는 구조, 5×5×5 = 125개 뉴런에서의 선행 검증입니다. **이 대안을 원래 완전 연결 구상의 확정된 대체안으로 취급하지 않습니다.** 논리적으로 연결 가능하다는 사실을 수식으로 표현하는 것과 각 연결의 독립 학습 상태를 저장하는 것도 별개입니다.

## 3. 세 좌표평면과 8색 논리

XY·XZ·YZ의 세 좌표평면이 **동작·사고·인식**을 각각 담당합니다. 각 평면에는 **R O Y G B M P W**의 기본 상태 8개를 둡니다. 사용자 설명의 핵심은 두 기준 방향 사이를 지나는 선분에서 색이 혼합되어 복합 의미가 만들어진다는 것입니다.

- 평면마다 기본 상태 8개를 사용합니다.
- 기준 방향 사이에 놓인 선분의 색을 혼합 규칙으로 계산합니다.
- 3차원 선분을 세 평면에서 읽어 동작·사고·인식의 표현을 구성합니다.
- 이런 선분들이 이어진 전체 경로를 하나의 생각으로 취급합니다.

아직 정하지 않은 사항:

1. 어느 평면을 어느 역할에 대응시킬지. 이전 설명의 XY=인식, XZ=사고, YZ=동작은 예시였습니다.
2. R/O/Y/G/B/M/P/W의 정확한 색값, 특히 유사한 색을 어떤 방식으로 구별할지.
3. 8개 색의 기준 방향 순서, 좌표축 기준, 정확한 각도 배치.
4. 실제 빛·물감·색 공간의 혼합을 사용할지, 별도로 정의한 8색 결합 연산을 사용할지.
5. 두 기준 방향 사이의 혼합 비율과 계산식.
6. 같은 색으로 보이는 서로 다른 혼합 이력을 하나의 상태로 묶을지 구분할지.
7. 한 평면으로의 투영 길이가 0인 선분을 처리하는 방법.
8. 실제 입력·기억·행동이 색 상태와 연결되고 학습되는 방법.

각도는 선분의 출발점에서 도착점으로 향하는 방향 벡터로 계산하자는 제안이 있습니다. 큐브 중심을 기준으로 위치를 읽는 규칙과는 다르며, 최종 명세에서는 구분해야 합니다.

같은 3차원 방향에서 나온 세 투영 각도는 독립적이지 않습니다. 한 선분의 세 역할 값을 완전히 독립적으로 정할 수는 없으므로, 이것을 의도한 결합 제약으로 사용할지 또는 경로·시간·내부 상태로 보완할지 검증해야 합니다. 이 제약은 긴 경로 전체의 표현력이 방향 하나의 표현력에 한정된다는 뜻은 아닙니다.

## 4. 시냅스굴절선과 생각의 보존

경로를 `P = (n0 → n1 → ... → nk)`라고 하면, 생각은 경로 P 전체입니다. 선분 i의 방향과 길이는 다음처럼 표현할 수 있습니다.

```text
d_i = position(n_(i+1)) - position(n_i)
L_i = length(d_i)
segment_i = (출발 뉴런, 도착 뉴런, 세 평면의 의미, 길이)
thought = 순서대로 이어진 segment들의 전체 경로
```

이는 사용자 구상을 기록하기 위한 표기이며 저장 형식을 확정한 것은 아닙니다. 생각을 재현하려면 최소한 경로 순서, 뉴런 위치 또는 이를 재구성할 정보, 색 규칙의 버전이 필요합니다. 시간차와 당시 시냅스 가중치·뉴런 상태까지 보존할 범위는 아직 정하지 않았습니다.

선분 길이가 의미의 가중이라는 원칙은 정해졌지만, 원래 길이를 사용할지 `L_i / 전체 길이`로 정규화할지, 길이를 실제 출력 결정에 어떻게 반영할지는 미정입니다. 길이 가중을 사용해 전체 경로를 평균값 하나로 축약하는 것은 사용자 구상을 보존하지 못할 수 있습니다.

같은 시작점·끝점에서도 중간 경로가 다르면 경로 표현은 다릅니다. 반대로 경로의 이동·회전·분할, 동일 뉴런의 재방문, 시간만 다른 경로를 언제 같은 생각으로 취급할지는 별도 동등성 규칙이 필요합니다. 그림에서 선이 교차한다는 것만으로 뉴런 또는 새 접속점이 생긴다고 정한 것은 아닙니다.

## 5. 감정 배정과 누적

사용자 구상:

- 기본 감정 몇 가지를 선택합니다.
- 뉴런마다 기본 감정을 배정합니다. 여러 뉴런이 같은 감정 유형을 가질 수 있습니다.
- 생각의 경로가 통과한 뉴런들의 감정을 합합니다.
- 이 합이 그 생각에 동반되는 최종 감정입니다.

기본 감정의 종류와 개수는 아직 확정하지 않았습니다. 앞서 제시된 기쁨·두려움·분노·슬픔은 예시입니다. 감정 성분별 벡터 합은 이를 구현하는 제안이며, 서로 다른 감정을 수 하나로 합쳐 구별을 잃지 않도록 합니다.

```text
emotion(P) = 경로에 기여하는 뉴런들의 기본 감정 벡터 합
```

감정 합에는 현재 선분 길이나 시냅스 학습 가중치를 자동으로 곱하지 않습니다. 그것은 사용자가 정한 별도 규칙이 아닙니다.

미정 사항은 감정 배정 비율·공간 분포, 감정 강도, 시작/끝 뉴런의 포함, 재방문마다 재합산할지 여부, 긴 경로의 감정 총량을 그대로 둘지 정규화할지, 감정 배정을 학습으로 바꿀 수 있을지입니다. 누적 감정이 이후 경로 선택과 학습에도 영향을 주는지 역시 미정입니다. 합산만 구현하면 감정은 생각의 결과값이고, 이를 다음 처리에 입력하면 작용하는 상태가 됩니다.

## 6. 서로 다른 세 값

| 값 | 위치 | 의미 |
|---|---|---|
| 기하학적 길이 | 경로의 각 선분 | 해당 선분 의미의 가중 |
| 학습 가중치 | 시냅스 | 활동 경험에 따라 변하는 연결 강도 |
| 기본 감정 | 뉴런 | 경로 통과에 따른 감정 기여 |

이 세 값을 하나로 합치거나 서로 대신 사용하지 않습니다. 색 혼합 비율 역시 시냅스의 신호 전달 강도와 다른 값입니다.

## 7. 최신 시냅스 학습 규칙 — 구현 완료

사용자는 처음 활성화될 때마다 아주 작은 가중치가 생기는 방식을 제안했고, 이후 인간 시냅스의 가소성 특징을 단순화해 넣도록 요청했습니다. 현재 `src/plastic-synapse.mjs`에 발화 시간차와 현재 가중치에 의존하는 `soft-bounded` STDP를 구현했습니다.

```text
dt = 받는 뉴런의 발화 시각 - 해당 시냅스 입력의 도착 시각
span = wmax - wmin

dt > 0: dw = +Aplus  * exp(-dt/tau) * (wmax-w)/span
dt < 0: dw = -Aminus * exp( dt/tau) * (w-wmin)/span
dt = 0: dw = 0

w_next = 범위 [wmin, wmax] 안으로 제한한 (w + dw)
```

| 기본 설정 | 값 |
|---|---:|
| 초기 전도도 | 0.4 nS |
| 하한 | 0.25 nS |
| 상한 | 14 nS |
| 강화 계수 | 0.001 nS |
| 약화 계수 | 0.001 nS |
| 시간상수 | 20 ms |

이 수치는 공학적 기본값입니다. 사람 시냅스에서 얻은 공통 상수 또는 사람과 거의 같은 동작을 입증한 값은 아닙니다. 현재 규칙은 흥분성 시냅스의 전도도 크기에 적용합니다. 새 시냅스의 기본 규칙이지만 모든 기존 연속 보상 회로에 자동으로 적용되는 것은 아닙니다.

기존 1.0.0 `additive-clipped` 규칙과 저장 형식은 유지하며, 새 형식은 2.0.0입니다. 이전 체크포인트는 이전 규칙으로 복원됩니다. 이력 최대 10,000회 이후에는 변경 전에 중단하므로 무기한 연속 학습을 위해서는 이력 관리 확장이 필요합니다.

현재 API는 호출자가 발화 시간쌍을 제공해야 합니다. 이번 통합 검증은 실제 발화·지연으로 얻은 시간을 사용하고, 학습된 전도도를 다음 시행에 전달하는 방식입니다. 모든 시냅스가 실시간 발화를 구독하는 온라인 GNN 실행기를 완성한 상태는 아닙니다. 전체 활동량 항상성, 억제성 가소성, 생화학적 칼슘 모델, 신경조절물질은 이번 추가의 범위가 아닙니다.

## 8. 현재 뉴런의 종류

Neuron Set에서 사용하는 세포는 **ControlNeuron 1.0.0**입니다. 출처 정보는 고전 오징어 Hodgkin–Huxley 참조와 6.3°C 조건을 명시하며, 여기에 흥분·억제 입력과 합성 적응 변수가 포함되어 있습니다.

인간 대뇌피질의 특정 층·세포형에 맞춘 뉴런은 아닙니다. 사용자는 유형을 질문했으며, 대뇌피질 모델로 교체하라는 결정은 아직 없습니다. 향후 전환을 원한다면 목표 세포형과 실측 검증 기준을 먼저 정해야 합니다. 이번 설계 정리와 시냅스 변경에서는 원본 세포 파일 7개를 수정하지 않았습니다.

2. **좌표와 색:** 단위·방향·역할 대응, 8색 값, 혼합 연산, 투영 예외.
3. **경로 생성:** 첫 발화의 입력, 다음 뉴런 선택, 여러 뉴런 동시 발화, 분기·병합, 순환·최대 길이·종료.

5. **생각의 저장:** 순서·시각·규칙 버전·상태 보존 범위, 생각의 동일성, 검색·재활성화·공유 경로.
6. **감정:** 종류·분포·강도·누적 기준·반복 방문·정규화·행동에 미치는 영향.
7. **시냅스 학습 연결:** 시간쌍 선택 정책, 온라인 갱신 시점, 보상 규칙과 결합 여부, 이력 한계 해결.
8. **안정성과 규모:** 총 흥분 입력, 억제, 순환, 가중치 포화, 지연, 잡음, RAM·저장·실행 시간 측정.
9. **소거 세포:** 실패 평가와 문맥 구분, 판정에 필요한 관측량, 경로 사용 억제 방식, 공유 연결의 유용성 확인, 소거 예산·대체 경로·복원 기간. 절차는 13절을 따르고 수치 기준은 검증 전에 고정합니다.

## 13. 소거 세포 — 반복 실패 경로의 선택적 정리

### 13.1 목적과 적용 범위

사용자 제안의 목적은 **실패를 반복하는 시냅스굴절선에 계속 의존하지 않고, 실패에 기여하는 연결을 정리하는 것**입니다. 이 목적을 유지하되, 경로 전체의 실패를 구성 시냅스 전부의 결함으로 취급하지 않습니다.

소거 세포는 우선 경로 기록·평가·연결 관리를 담당하는 소프트웨어 기능으로 설계합니다. 실제 발화하는 별도 뉴런으로 구현할지, 분산된 관리 기능으로 구현할지는 미정입니다. 실제 뇌의 특정 세포를 그대로 복제한 모델이라는 뜻은 아닙니다.

**굴절선의 사용 중지와, 그 굴절선에 속한 모든 시냅스의 삭제를 구분합니다.** 경로를 억제해도 그 구성 시냅스를 다른 유용한 경로에서 사용하는 것은 허용합니다. 경로별 선택 확률·사용 상태를 관리하는 계층은 아직 구현되지 않았으며 선행 구현 항목입니다.

### 13.2 실패 판정

- 실패는 과제에서 관측 가능한 결과와 평가 기준으로 정의합니다. 부정적인 감정값, 색, 발화가 적다는 사실만으로 실패를 판정하지 않습니다.
- 경로 ID와 버전, 실행 ID, 입력·과제 문맥, 평가 시각, 성공·실패·미확정 결과, 보상 신뢰도와 지연 상태를 연결해 기록합니다. 아직 해결되지 않은 경로 동등성 문제는 4절을 따르며, 다른 버전·문맥의 기록을 무조건 합치지 않습니다.
- 보상이 늦게 도착하는 실행은 정산 전까지 미확정입니다. 누락·중복·순서 역전·평가 오류를 구분하고 같은 실행을 여러 실패로 세지 않습니다. 마감 이후 도착한 보상의 처리 규칙도 미리 정합니다.
- 연속 실패 횟수만 사용하지 않고, 시도 횟수 대비 실패율, 성공 이력, 목표·환경 변화, 학습 기회, 평가 신뢰도를 함께 봅니다. 같은 조건의 반복만으로 독립적인 증거가 충분히 쌓였다고 가정하지 않습니다.
- 보상 자체에 오류가 있을 수 있으므로 부호를 곧바로 확실한 정답·오답으로 취급하지 않습니다. 신뢰도를 판단할 근거가 부족하면 영구 소거를 보류합니다. 평가 근거와 신뢰도 추정법은 미정입니다.
- 평가기에서 사용할 수 있는 정보와 학습기가 관측할 수 있는 정보를 구분합니다. 숨겨진 정답이나 실험용 목표 전환 표시를 실사용 가능한 신호인 것처럼 연결하지 않습니다.

### 13.3 처리 순서

| 단계 | 동작 | 다음 단계로 넘어갈 조건 |
|---|---|---|
| 관찰 | 경로별 성공·실패와 보상 정산 상태를 기록 | 비교 가능한 실패 증거가 충분함 |
| 의심 표시 | 실패 경로를 후보로 표시하고 문맥별 성능을 검토 | 보상 오류·학습 부족 등의 설명을 검토함 |
| 임시 억제 | 해당 문맥에서 경로 선택 확률을 낮추거나 일시 사용 중지 | 대체 경로 또는 보류 동작이 있으며 복원 가능함 |
| 원인 분리 | 일부 연결의 약화·차단 효과를 대조 조건과 비교 | 실패 감소와 다른 성공 과제의 보존을 확인함 |
| 선택적 소거 | 유해한 기여가 확인된 연결을 우선 논리적으로 비활성화 | 공유 연결·실행 중 참조·구조 안정성 검사를 통과함 |
| 사후 확인 | 재학습·다른 문맥·목표 유지/전환 성능을 평가 | 기준을 만족하면 유지, 악화하면 복원함 |

‘몇 번 실패하면 삭제’라는 고정 횟수는 아직 정하지 않습니다. 충분한 관측 수, 신뢰도 기준, 억제 기간, 허용 성능 저하, 단계별 소거량은 별도 실험 전에 고정하며 결과를 보고 유리하게 바꾸지 않습니다.

### 13.4 공유 연결 보호와 전체 경로 소거의 예외

예를 들어 `A→B→C→D`가 실패해도 `A→B→C→E`가 성공한다면, 공통 연결 `A→B`와 `B→C`를 실패 경로에 속했다는 이유만으로 지우지 않습니다. 그렇다고 `C→D`가 원인이라고 즉시 단정하지도 않으며, 연결별 또는 작은 연결 묶음별 차단 비교로 확인합니다.

공유 여부뿐 아니라 어떤 문맥에서 성공에 기여했는지 추적합니다. 등록된 성공 경로에서 쓰이지 않았다는 사실만으로 미관측 용도가 없다고 단정하지 않습니다. 영향이 확인되지 않은 공유 연결은 보호합니다.

경로를 구성하는 모든 연결의 소거는 다음 조건을 모두 확인한 제한적 예외로 둡니다.

1. 해당 연결들이 그 경로에 전용으로 쓰이고, 확인한 다른 성공 경로를 훼손하지 않습니다.
2. 실패가 충분히 신뢰할 수 있는 평가에서 재현되며 일시적 교란으로 설명되지 않습니다.
3. 대체 경로가 검증됐거나, 추가 손상 없이 실행을 보류할 수 있습니다.
4. 삭제 전 상태와 관련 이력을 복원할 수 있고, 사후 성능 확인을 수행합니다.

### 13.5 연결 변경과 진행 중 신호의 일관성

- 경로는 시냅스 ID와 버전을 참조합니다. 소거된 연결의 ID를 바로 재사용해 과거 발화·보상이 새 연결에 적용되는 일이 없어야 합니다.
- 실행 중인 굴절선, 전달 대기 신호, 미도착 보상, 저장된 생각의 참조를 확인한 일관된 경계에서 변경합니다. 기존 이벤트를 정산하거나 취소하는 규칙을 명시하며 조용히 누락시키지 않습니다.
- 논리적 비활성화는 새로운 경로 선택에서 연결을 제외하는 조치입니다. 가중치 감소와 별개이며, 단순히 저장 배열에서 원소를 없애는 동작으로 대체하지 않습니다.
- 소거 후 입력에서 출력으로 이어지는 필요한 경로, 억제 연결, 고립 뉴런·순환·활동량 제한을 확인합니다. 흥분성 연결과 억제성 연결을 같은 효과로 취급하지 않습니다.
- 한 번에 변경하는 연결 수·비율과 재평가 간격을 제한합니다. 대체 경로 탐색·연결 재형성에도 자원 예산을 두며, 실패할 때마다 삭제와 생성을 무한 반복하지 않습니다. 대체 경로가 계속 실패하면 입력·평가·학습 규칙의 문제도 재검토합니다.

### 13.6 보존과 복원

소거 전 연결·가중치·관련 학습 상태·경로 버전·판정 근거를 복원 기록에 남깁니다. 과거 생각의 경로 순서, 색 규칙, 의미와 감정 기록은 해당 버전의 이력으로 보존합니다. 현재 연결을 소거했다는 이유로 과거 생각 자체를 삭제하거나 다른 의미로 재해석하지 않습니다. 연결 소거만으로 뉴런의 좌표·기본 감정을 변경하지 않습니다.

소거 후 다른 성공 과제의 악화, 대체 경로 상실, 허용 범위를 벗어난 활동 변화가 확인되면 변경을 되돌립니다. 복원은 대기 이벤트·가중치·참조 관계까지 일관되게 수행해야 합니다.

논리적 비활성화만으로 디스크 사용량이 즉시 줄지는 않습니다. 물리적 저장공간 회수는 진행 중 참조가 없고 복원·이력 보존 정책을 만족한 뒤 별도 압축·정리 절차로 수행합니다. 보존 기간과 저장 예산은 미정입니다. 이 설계 추가로 현재 실험 파일을 삭제하지 않습니다.

### 13.7 구현 후 검증할 항목

다음은 향후 검증 계획이며 현재 통과한 실험 목록이 아닙니다. 모든 신경망 실험은 Neuron Set에서 수행합니다.

1. 소거 없음, 임시 경로 억제, 선택적 소거를 같은 입력·평가 조건에서 비교합니다. 전체 경로 소거 비교가 필요하면 복제된 작은 회로와 복원 가능한 환경에 한정합니다.
2. 정상 보상, 잘못된 보상, 지연·누락·중복, 목표 유지·전환을 나눠 평가합니다. 평가 신뢰도가 낮은 경우 유용한 연결을 잘못 소거하는 비율을 측정합니다.
3. 실패 경로와 성공 경로가 시냅스를 공유하는 사례에서 성공 능력이 보존되는지 확인합니다. 전용 실패 경로의 제거와 대체 경로의 회복도 평가합니다.
4. 잘못된 선택·동시 선택·무응답·실행 거부를 별도로 집계합니다. 답을 내지 않거나 경로를 모두 없앤 결과를 정확도 개선으로 처리하지 않습니다.
5. 소거 직전·직후 저장, 미도착 보상, 복원, 연결 버전 변경과 재형성을 검증합니다. 원시 기록을 별도로 재검산하고 수치 정밀도에 따른 결과 변화도 확인합니다.
6. 성공 기억의 손실, 새 과제 적응, 재학습 비용, 연결 수·RAM·디스크·실행 시간과 새 시드 재현성을 함께 평가합니다.

### 13.8 근거와 현재 한계

실험 36은 이전 단계 보상의 학습 효과를 제거했을 때 교대 목표에서 149/216→168/216으로 개선됐지만, 무작위 목표의 유지 구간에서는 81/81→80/81로 악화한 결과입니다. 이는 문맥에 따라 유용한 정보를 제거할 수 있음을 보여주는 참고 자료이며, **시냅스 연결 소거 자체를 검증한 결과는 아닙니다.** 실험 36 결과 (original reference: `experiments/36-boundary-feedback/RESULTS.md`)

생물학적으로는 교세포의 시냅스 제거가 학습·기억과 관련된다는 연구가 설계에 영감을 줍니다. 그러나 실제 뇌에 ‘실패한 생각 전체를 판단해 삭제하는 소거 뉴런’이 확인됐다는 근거로 해석하지 않습니다. [학습 중 교세포의 시냅스 제거 연구](https://www.nature.com/articles/s41593-022-01184-5), [미세아교세포의 시냅스 제거와 망각 연구](https://pubmed.ncbi.nlm.nih.gov/32029629/)

현재 확정한 것은 소거 세포의 목적과 위 보호 원칙을 설계에 포함한다는 점입니다. 평가 공식·임계값·관리 구조·연결 생성 및 재형성 규칙은 미정이며, 구현 완료나 성능 보장으로 표시하지 않습니다. **니온 GNN 형성과 기능적 자아 계획의 보류 상태를 유지합니다.**
